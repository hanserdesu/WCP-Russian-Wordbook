# 俄语词库质量优化与全量资源对齐方案

## 1. 目标与范围
本方案解决当前俄语词库与资源链条中存在的品质与对齐缺口：
1. **重音质量优化**：修复 `russian_books.json` 中 81 个多音节词缺失重音标注的问题，确保规范重音全覆盖。
2. **音频资源补齐**：
   - 清除 A1 唯一缺失词 `вот` 的失败标记并生成其单词音频，达到 A1/A2 级别 100% 单词音频全覆盖（2,930/2,930 词）；
   - 保持后台 Edge-TTS 单词音频与例句音频持续断点续传生成。
3. **全链路重新对齐与打包**：
   - 更新 `output/russian_books.json`；
   - 重新灌注游戏主数据库 `wcpFullEng.db` 与 `wcpOnlyWord.db`；
   - 重新生成官方 Excel 导入包（`俄语A1A2.xlsx`、`俄语B1.xlsx`、`俄语B2.xlsx`）及 `wcp_russian.db`；
   - 重新生成 `MyBook.es3` 槽位 3 词书数据并保证指纹三方同步；
   - 重新导出 `ru_db_payload` 离线自愈补丁包与 manifest；
   - 运行 `verify_all_ru.py` 进行 17 项全指标闭环验收。

## 2. 实施步骤

### 阶段一：重音数据补全与校准
1. **提取 81 个缺失重音的多音节词**（如 `бонжур`, `йена`, `ожерелие`, `пристегнуться`, `аппетитно`, `щекотно` 等）。
2. **注入规范重音标记**（添加标准西里尔组合重音符 `\u0301` 或显式重音元音，如 `бонжу́р`, `йе́на`, `ожере́лие`, `пристегну́ться`, `аппети́тно` 等）。
3. **回写 `output/russian_books.json`**，确保除天然单音节词外所有多音节词均有合法重音。

### 阶段二：单词音频 A1 补齐与后台任务维护
1. **重试生成 A1 单词音频 `вот`**：调用 `edge-tts` 生成并放置于 `%USERPROFILE%\AppData\LocalLow\WCP\vocabulary\вот.mp3`，并在 `output/audio_manifest_ru.json` 中将其标记为 `done`。
2. **单词音频就绪验证**：达成 A1 (985/985, 100%) 与 A2 (1945/1945, 100%) 全量就绪。
3. **后台音频继续推进**：保留现有的 B1/B2 单词音频与例句音频后台生成进程，后台持续增量下载。

### 阶段三：全链路数据库与资源重新对齐
按规范次序依次执行管线脚本：
1. `python tools/apply_sentences.py`：重新结算并校验 `data/translations/sentences_master.json`。
2. `python tools/patch_local_db_ru.py --force`：将补齐重音后的最新词条灌入 `wcpFullEng.db` 与 `wcpOnlyWord.db`。
3. `python tools/make_import_files.py`：重新构建无表头 `俄语A1A2.xlsx`, `俄语B1.xlsx`, `俄语B2.xlsx` 及 `wcp_russian.db`，并同步到游戏持久化目录。
4. `python tools/write_mybook_ru.py`：重新构建 `MyBook.es3` 槽位 3（8,451 词），确保 ES3 `__type` 完整且槽位 1（日）槽位 2（法）不受影响。
5. `python tools/export_ru_db_payload.py`：重新生成 `ru_pron.tsv`, `ru_sentences.tsv`, `ru_only_pron.tsv` 及 SHA-256 `manifest.json`。
6. `python tools/build_catbar_russian_payload.py`：重新核验词书指纹三方一致性（MyBook 词表、C# 常量 `BookProfiles.cs`、CatBar payload）。
7. `python tools/build_installer_payload_ru.py`：更新一键安装包资源。

### 阶段四：全量验收与复查
1. 运行 `python tools/verify_all_ru.py` 验证：
   - 词书构建：8,451 词
   - 例句 master：8,451 词 × 3 = 25,353 条
   - 单词音频：A1/A2 100% 覆盖
   - 例句音频提取契约 `ExtractRu`：0 漂移
   - 数据库表项、MyBook 词数与指纹、导入文件无表头契约、自愈包等 17 项全绿。
